# Bundled fonts

- **DejaVu Sans, Serif, and Sans Mono**: [DejaVu Fonts](https://dejavu-fonts.github.io/), version 2.37. Bitstream Vera license; see `DejaVu-LICENSE.txt`.
- **Atkinson Hyperlegible**: [Braille Institute](https://www.brailleinstitute.org/freefont/), distributed through [Google Fonts](https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegible). SIL Open Font License; see `AtkinsonHyperlegible-LICENSE.txt`.
- **OpenDyslexic**: [OpenDyslexic](https://opendyslexic.org/), TTF files from the [original project archive](https://github.com/antijingoist/open-dyslexic/tree/master/ttf). SIL Open Font License; see `OpenDyslexic-LICENSE.txt`. Current upstream: https://forge.hackers.town/antijingoist/opendyslexic.

Fonts are served locally. HTML and EPUB exports include the chosen font; generated PDFs embed a font subset. No external font service is contacted.
